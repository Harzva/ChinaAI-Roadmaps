学习教程

推荐先看路线，再读论文，最后回到问答页复盘。这样不会一开始就陷进大量模型细节里。

  1. 先浏览四个专题卡片，确定你要研究的模型家族。
  2. 打开对应的 `*_analysis.html`，先读时间线和技术路线分析。
  3. 下载原论文，重点看摘要、方法框图、训练设置和实验表格。
  4. 回到单篇 Markdown 解析页，用问答部分检查理解。
  5. 把 `*_flowchart_final.svg` 作为分享稿或课程大纲的骨架。
