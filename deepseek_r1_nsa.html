DeepSeek‑R1 与 Native Sparse Attention：激励推理与稀疏注意力

DeepSeek 在 2025 年推出 DeepSeek‑R1 和 Native Sparse Attention (NSA)，分别关注利用强化学习提升推理能力和在硬件友好的情况下实现长上下文稀疏注意力。

DeepSeek‑R1：激励推理能力

  • 强化学习奖励设计：R1 的核心是通过 RL 激励模型执行更复杂的思考步骤。团队设计了一种 Generalist Reward Modeling (GRM) 策略，在推理时根据任务完成度和推理深度生成奖励，引导模型深入思考。
  • 任务合成与探索：R1 在大量复杂任务上进行训练，包括数学、代码和知识检索，通过 RL 使模型学会规划、搜索和自我纠错。
  • 性能提升：R1 在长序列任务和思考链任务上的表现优于常规微调模型，并显现出更强的泛化能力。

Native Sparse Attention (NSA)：硬件对齐的稀疏注意力

  • 硬件友好设计：NSA 提出一种原生支持稀疏模式的注意力算法，能够在 GPU 等硬件上高效实现稀疏乘法运算，减少缓存碎片和内存浪费。
  • 兼顾长上下文与效率：通过块稀疏与局部全连接结合，NSA 支持百万级 token 长度的上下文，同时计算复杂度和内存开销显著降低。
  • 集成与应用：NSA 被用于 DeepSeek‑V3 系列中，证明其在语音识别、文档摘要和代码分析等任务中能保持性能并降低成本。

总结

DeepSeek‑R1 与 NSA 分别从算法和硬件两个角度改进模型推理：前者通过设计通用奖励模型鼓励深度推理，后者提供硬件友好的稀疏注意力实现，二者结合为后续的 DeepSeek‑V3 系列奠定基础。
