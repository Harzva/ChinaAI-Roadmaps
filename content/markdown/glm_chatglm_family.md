# ChatGLM 系列综述

ChatGLM 系列是在 GLM‑130B 基础上发展出的中文对话大模型家族，融合了监督微调、指令调优和强化学习来提升对话能力。该系列覆盖从 6B、13B 到 130B 的不同尺寸，并随着版本迭代在长上下文、代码生成和多模态方面持续进化。

## ChatGLM 1/2/3

最初的 **ChatGLM** 采用了指令微调技术，使 6B 规模的模型能够在中英双语环境下进行自然对话。随后发布的 **ChatGLM 2** 通过引入更大的 **32K 上下文窗口**、增加代码数据和数学推理训练，在 MMLU 及 C‑Eval 等基准上显著提高表现。**ChatGLM 3** 进一步引入强化学习和人类反馈，提升了长文本对话和复杂任务执行能力。

## GLM‑4 系列（ChatGLM 4）

2024 年，团队推出 **GLM‑4** 系列，它实际上也是 ChatGLM 家族的升级版，包含多个子模型：

- **GLM‑4‑Air**：约 9B 参数，针对移动端和边缘设备优化，兼顾性能和成本。
- **GLM‑4**：主力模型，采用稀疏专家架构，在相同推理开销下提供更大的总参数规模，并支持 **128K** 以上的长上下文。
- **GLM‑4V**：加入视觉编码器，能够理解图像和图表并与文本进行联合推理。
- **GLM‑4‑All Tools**：在语言模型基础上引入工具调用框架，可以访问搜索、代码执行、绘图等外部插件，体现了向智能体方向的迈进。

这些模型在问答、编码、数学和多模态任务上取得领先，并通过插件机制扩展模型的应用场景。

## 技术亮点

* **监督微调 + 指令蒸馏**：ChatGLM 系列采用中文问答数据和命令式指令进行微调，使模型更贴近用户需求。
* **长上下文处理**：从 ChatGLM 2 起显著扩展了上下文窗口，利用稀疏注意力机制，在生成长文档时保持一致性。
* **多模态能力**：GLM‑4V 通过视觉编码器使模型具备图文理解能力，支持例如表格理解、绘图问答等任务。
* **工具调用**：GLM‑4‑All Tools 提供了插件接口，允许模型在对话中调用外部搜索引擎、计算器或代码执行环境，提升真实任务完成度。

## 总结

ChatGLM 系列展示了 GLM 家族从通用语言模型向多模态智能体演进的路线。它不仅在开放领域对话上表现出色，还通过长上下文、代码能力和外部工具调用，拓展了模型在生产力和智能体领域的应用范围。

## 问题与回答

1. **问：ChatGLM 系列包含哪些代表性模型？**
   **答：** 该系列包括 ChatGLM 1/2/3 以及升级版 GLM‑4 系列（含 Air、主力版、4V、All Tools 等），覆盖 6B、9B、13B、130B 等多种规模。

2. **问：这些版本在对话能力上有哪些进步？**
   **答：** ChatGLM 1 通过指令微调具备基本对话能力，ChatGLM 2 在长上下文和代码、数学推理上大幅提升，ChatGLM 3 加入强化学习反馈，能够处理复杂任务；GLM‑4 系列进一步拓展了工具调用和多模态推理。

3. **问：长上下文能力是如何实现的？**
   **答：** 从 ChatGLM 2 开始采用稀疏注意力和缓存技术，将上下文窗口扩展至 32K 甚至 128K 以上，使模型能够处理长文档并保持一致性。

4. **问：GLM‑4‑Air 有何特点？**
   **答：** 它是轻量化版本，约 9B 参数，针对移动端和边缘设备优化，在保证推理速度的同时兼顾一定的理解和生成能力。

5. **问：GLM‑4V 如何实现多模态？**
   **答：** 通过集成视觉编码器，将图像与文本联合编码，模型可以执行图文问答、表格理解和绘图等任务，提升了多模态交互能力。

6. **问：All Tools 模式有什么作用？**
   **答：** GLM‑4‑All Tools 提供插件接口，使模型能在对话中调用外部搜索、计算器、代码执行等工具，形成简单的智能体，解决现实任务。

7. **问：如何对模型进行监督微调和指令蒸馏？**
   **答：** 团队收集了大量中文问答和命令式指令数据，先进行有监督微调使模型适应对话场景，再通过指令蒸馏和 RLHF 提升遵从性和安全性。

8. **问：在代码能力方面有哪些成果？**
   **答：** ChatGLM 2 开始加入大量代码数据和工具使用示例，使模型能够理解代码、生成函数并通过 All Tools 执行测试，从而在编程任务中表现优异。

9. **问：与其他中文大模型相比优势是什么？**
   **答：** ChatGLM 系列在中文对话自然度、长文本理解和多模态能力上具有优势，同时支持工具调用，这些特性使其在教育、内容创作和办公场景中更具实用价值。

10. **问：未来的发展方向是什么？**
    **答：** 团队计划在 GLM‑5 系列上进一步提升自适应稀疏注意力、异步强化学习和智能体框架，拓展为通用多模态智能体。
