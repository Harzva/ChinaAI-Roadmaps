# WebGLM: Towards an Efficient Web-Enhanced Question Answering System with Human Preferences

**WebGLM** 是智谱团队于 2023 年提出的检索增强问答系统，将大型语言模型与互联网检索结合，提升模型回答事实性问题的能力。传统的大模型无法访问最新信息，WebGLM 在生成回答之前先搜索网络并提取候选内容，然后通过模型排序和摘要，结合人类偏好进行微调，使回答更加准确且具备时效性。

## 关键技术

- **检索与生成融合**：系统首先调用搜索引擎检索答案候选，再用语言模型对候选进行筛选和总结，最终生成回答。
- **人类偏好训练**：通过人类打分和偏好优化（DPO/RLHF）让模型学会更好地利用检索结果，避免幻觉和过度编造。
- **模块化设计**：WebGLM 作为 ChatGLM 系列的插件可独立更新，使模型随时获取最新信息。

## 应用

WebGLM 对提升问答系统在时效性和准确度方面有重要作用，特别适合新闻、科普等需要实时信息的场景。在国内外的评测中，WebGLM 在事实性问答准确率上明显优于纯语言模型基线。

## 问题与回答

1. **问：什么是 WebGLM？**
   **答：** WebGLM 是一个检索增强问答系统，结合搜索引擎和大型语言模型，通过在生成回答前检索并整理互联网信息，提高回答的事实性和时效性。

2. **问：WebGLM 为什么需要检索功能？**
   **答：** 传统的大模型知识库有限且无法实时更新，通过检索获取最新信息，模型可以在回答事实性问题时引用权威来源，减少幻觉。

3. **问：系统的工作流程是怎样的？**
   **答：** 首先发送查询到搜索引擎检索候选片段，然后语言模型根据相关性和可信度对这些片段进行排序和摘要，最后生成结合多方信息的回答。

4. **问：如何通过人类偏好训练模型？**
   **答：** WebGLM 利用人工标注的排序和质量评价，通过偏好优化或强化学习细调模型，使其更好地利用检索内容而不是盲目生成。

5. **问：检索部分是否影响模型流畅性？**
   **答：** 系统采用模块化设计，检索和生成并行进行，增加的延迟较小；对于需要最新信息的问答，这种延迟是值得的。

6. **问：如何保证检索内容的可信度？**
   **答：** 系统可配置可信网站列表，并在排序阶段考虑来源可靠性；用户也可以对回答进行反馈，进一步优化模型。

7. **问：WebGLM 与 RAG（Retriever‑Augmented Generation）有什么区别？**
   **答：** RAG 是一种泛称，WebGLM 在此框架下加入了人类偏好训练和面向中文的优化，并集成到 ChatGLM 系列中作为插件模块。

8. **问：该系统适用于哪些场景？**
   **答：** 适用于新闻问答、百科查询、政策法规咨询等需要实时更新和高事实准确性的领域。

9. **问：WebGLM 如何与 ChatGLM 集成？**
   **答：** WebGLM 可以作为 ChatGLM 的外部工具插件，通过 API 调用实现无缝接入，保持 ChatGLM 在离线状态下的独立生成能力。

10. **问：目前的限制或挑战是什么？**
    **答：** 模型的准确度依赖于搜索结果质量，且需要合理设定检索范围。未来可探索更复杂的推理和多轮检索策略。
